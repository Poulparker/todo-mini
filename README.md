# Мини-задачник

Простое веб-приложение для ведения списка дел прямо в браузере: задачи сохраняются в `localStorage`, сервер не нужен.

**Стек:** HTML, CSS, JavaScript (без зависимостей).

## Запуск

Вариант 1 — открыть файл `index.html` в браузере (двойной клик).

Вариант 2 — через локальный сервер:

```bash
python -m http.server 8000
```

и открыть http://localhost:8000

## Что уже работает

- добавление задачи с проверкой ввода (пустой, повтор, слишком длинный текст);
- отметка «выполнено» и удаление задачи;
- счётчик выполненных задач и кнопка «Удалить выполненные»;
- фильтры «Все / Активные / Выполненные» с количеством задач, выбранный фильтр запоминается;
- сохранение списка после перезагрузки страницы;
- светлая и тёмная тема по настройкам системы.

## Хранение данных

Всё состояние лежит в `localStorage` браузера одной записью под ключом `todo-mini.v1`:

```json
{
  "version": 1,
  "tasks": [{ "id": "…", "text": "Купить продукты", "done": false, "createdAt": 1794414936452 }],
  "filter": "active",
  "draft": "Подготовить отчёт"
}
```

- после закрытия вкладки или перезапуска браузера восстанавливаются задачи, выбранный фильтр и недописанный текст в поле ввода;
- задачи из старой версии (ключи `todo-mini.tasks` и `todo-mini.filter`) переносятся автоматически;
- изменения, сделанные в другой вкладке, сразу появляются в открытой.

Посмотреть данные: F12 → Application → Local Storage. Ключей API и других секретов приложение не хранит.

## Обработка ошибок

| Ситуация | Что видит пользователь |
| --- | --- |
| Пустой ввод или только пробелы | «Введите текст задачи.» |
| Такая задача уже есть (без учёта регистра и лишних пробелов) | «Задача «Купить продукты» уже есть в списке.» |
| Текст длиннее 200 символов | «Слишком длинная задача: 250 символов, можно не больше 200.» |
| Данные в `localStorage` повреждены | Жёлтое предупреждение; список начинается заново, а старые данные сохраняются под ключом `todo-mini.v1.backup` |
| Не удалось сохранить (хранилище недоступно или переполнено) | Жёлтое предупреждение, что изменения пропадут после закрытия вкладки |

При ошибке ввода текст остаётся в поле и подсвечивается красным, чтобы его можно было исправить.

## Планы

1. Сроки выполнения и сортировка по дате.
2. Поиск по задачам.

## Ручные проверки

1. Добавить 2–3 задачи — они появляются в списке.
2. Нажать «Добавить» с пустым полем — появляется сообщение об ошибке.
3. Отметить задачу — текст зачёркнут, счётчик обновился.
4. Перезагрузить страницу (F5) — задачи на месте.
5. Удалить задачу крестиком и через «Удалить выполненные».
6. Переключить фильтры «Активные» и «Выполненные» — в списке только нужные задачи, счётчики в кнопках верные.
7. Выбрать «Выполненные» и добавить задачу — фильтр переключается на «Все», новая задача видна.
8. Ввести текст, не нажимая «Добавить», закрыть вкладку и открыть снова — текст остался в поле.
9. Открыть задачник в двух вкладках и добавить задачу в одной — она появляется во второй.
10. Добавить «Купить продукты», затем ввести «  купить   ПРОДУКТЫ » — сообщение о повторе, задача не добавлена.
11. В консоли (F12 → Console) выполнить `localStorage.setItem('todo-mini.v1', '{"tasks": [битые данные')` и обновить страницу — предупреждение о повреждённых данных, копия в `todo-mini.v1.backup`, задачник работает.
